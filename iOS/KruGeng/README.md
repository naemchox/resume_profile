# KruGeng

The KruGeng iOS app — a SwiftUI guided wizard that takes a song from file (or YouTube via an optional local server) through stem separation, note transcription, notation, and export of tabs/MIDI. The design is a "luxury · minimal · bright" paper-and-sapphire aesthetic ported from the project's web app.

## Contents

- **KruGeng/** — all Swift source: app entry point plus the `Components`, `DesignSystem`, `Models`, `Services`, and `Views` folders.
- **KruGeng.xcodeproj/** — the Xcode project (not documented here).
- **Info.plist** — app configuration (e.g. file-sharing for the library).
- **swiftui.md / swiftui.txt** — bundled SwiftUI reference notes used while building the UI.
