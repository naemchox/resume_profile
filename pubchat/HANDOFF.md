## 1. เริ่มงานบนเครื่องใหม่ยังไง

```bash
git clone https://github.com/monmon7735-coder/pubchat.git
cd pubchat
# เสิร์ฟไฟล์เดียว ไม่ต้อง build (Babel รันในเบราว์เซอร์)
npx serve . -l 8788          # หรือ python -m http.server 8788
# เปิด http://localhost:8788/
```

- Firebase config ฝังอยู่ใน `talk.html` แล้ว (โปรเจกต์ `chat-planner-1a45c` ใช้ร่วมกับแอปอื่น — ดู `BACKEND-SETUP.md`)
- deploy: `firebase deploy --only hosting` (predeploy คัด `talk.html` → `public/index.html` ให้เอง ดู `firebase.json`)
- แก้ rules: `firestore.rules` → `firebase deploy --only firestore:rules`

**ก่อนแก้โค้ดทุกครั้ง** — `talk.html` ~3,400 บรรทัดในไฟล์เดียว: แก้ทีละจุด แล้วเช็ค syntax ก่อน commit
(ดึง `<script type="module">` ออกมาไฟล์ `.mjs` แล้ว `node --check`)

## 3. การตัดสินใจที่ห้ามลืม (มีที่มา อย่ารื้อโดยไม่มีเหตุใหม่)

**3.1 เข้าฟรี เก็บเงินทีหลัง — เจ้าของตัดสิน 17 ส.ค. โดยเห็นตัวเลขแล้ว**
audit ตีราคา freemium ตลาดนี้ไว้ที่ ARPU ~$4.20 · conversion ~3.5% · CAC $0.5-3 เทียบกับคลับปิด 30 คน × ฿9,900 = ฿297,000
เจ้าของเลือกทางฟรีทั้งที่รู้ตัวเลข → **จดไว้เพื่อวัดผลจริงทีหลัง ไม่ใช่เพื่อเถียงใหม่**

**3.2 เงินซื้อ "ชั้นสมาชิก" ได้ · ซื้อ "คะแนนพฤติกรรม" ไม่ได้เด็ดขาด**
ถ้าเงินขยับอันดับได้เมื่อไหร่ = เรากำลังขายการเข้าถึงคนที่ไม่ได้ยินยอมให้ถูกประมูล (Tinder ELO เป็นตัวอย่างที่หลุด) → รายละเอียดใน `RANKING-SPEC.md`

**3.3 โควตาคำเชิญ = สิ่งเดียวที่เงินซื้อได้จริงในโค้ดตอนนี้**
`plan` ถูกอ่านที่เดียวคือ `inviteQuota()` (`talk.html:586`) → จุดขายจึงอยู่ที่ **ตอนคำเชิญหมด** ไม่ใช่หน้าราคา

**3.4 ทำไมไม่มี "ใครสนใจคุณ" ให้ขาย (แบบ Tinder Gold)**
คำเชิญ = เปิดห้องแชททันที ทั้งสองฝั่งเห็นกันอยู่แล้ว ไม่มีสถานะซ่อนให้ปลดล็อก — ถ้าจะขายของแบบนั้น **ต้องเปลี่ยนกลไกคำเชิญเป็น 2 จังหวะก่อน** (ยังไม่ทำ)

## 4. คู่แข่ง — ข้อด้อยที่ฉวยได้ และเรายืนตรงไหน

### ข้อด้อยจริงของแอปหาคู่ (เรียงจากที่ฉวยได้ง่ายสุด)

| # | ข้อด้อยของเขา | ของเรา |
|---|---|---|
| 1 | **แชทตายในแอป ไม่เคยแปลงเป็นการเจอตัวจริง** (burnout ~78-80%) | ⭐ compass + QR ยืนยันการเจอ = "แอปที่นับแค่การเจอจริง" — มีในโค้ดแล้ว |
| 2 | **เพศไม่บาลานซ์** (Tinder ชาย 76%) ชายไม่มี match / หญิงถูกถล่ม → ออกทั้งคู่ | คุมด้วย **ราคา** ไม่ใช่การคัด (ฝั่งที่ขาดเข้าถูกกว่า/ฟรี ประกาศเปิดเผยได้) |
| 3 | **จ่ายเพื่อ "ความชัดเจน"** — ใครกดไลก์/ตัวกรอง อยู่หลัง paywall (ผู้จ่าย Tinder 11.1M→8.77M, Bumble -16%/ปี) | เก็บค่า **verify + สิทธิ์ส่งความสนใจ** ไม่ใช่ค่าเข้าถึงคน |
| 4 | **โปรไฟล์ปลอม/สายขายบริการ/สแกม** (ไทยหนักมาก) | pool verified + โชว์ชั้นการยืนยันตัวตน |
| 5 | **ghosting / match แล้วเงียบ** | แชท 24 ชม. = ฟีเจอร์ ไม่ใช่บั๊ก |
| 6 | ตัดสินจากรูปล้วน | (ระวัง: แอป blind-date retention ต่ำมาตลอด — อย่าทุ่มทางนี้) |
| 7 | เจตนาไม่ตรงกัน (จริงจัง/ชั่วคราว/เพื่อน) | intent = ตัวกรองแข็ง ไม่ใช่ข้อความใน bio |
| 8 | ความปลอดภัยผู้หญิงตอนไปเจอ | นัดที่สาธารณะเท่านั้น + ยืนยัน 2 ฝ่าย |
| 9 | ไม่มี feedback ว่าทำไมพลาด | ขายได้ ความเสี่ยงต่ำ (ยังไม่ทำ) |
| 10 | ELO ซ่อนคุณถ้าไม่จ่าย ไม่โปร่งใส | จับคู่ ±1 ชั้น + ไม่โชว์คะแนนใคร |
| 11 | **cold-start ตามพื้นที่ = ตัวฆ่าอันดับ 1** | เปิดทีละ venue/มหาลัย ไม่ใช่ทั้งประเทศ |

### ไอเดียที่เช็คแล้วว่ามีเจ้าอื่นทำ (อย่าเสียเวลาซ้ำ)
- "ปัดน้อยลง เจอคนที่ใช่เลย" → Hinge, Coffee Meets Bagel ทำแล้ว · **ปัญหาจริงไม่ใช่ UI แต่คือของในสต็อก** (user 200 คนยื่นคนที่ใช่ไม่ได้)
- "กรองบุคลิก/LGBTQ+" → Tinder/Bumble/HER/Taimi มีแล้ว · **Boo = MBTI + % compatibility ตรงเป๊ะ** · ตัวกรอง self-report **โกหกได้** → ของจริงต้องกรองจาก**พฤติกรรม**

### จุดยืน (ช่องว่างที่ควรยืน)
Bangkok Matching ครองบนสุดมา 19 ปีที่ ฿25,000+ → **เราเล่น ฿3,000-9,900 กลุ่มอายุ 25-35** ที่รู้สึกว่า *"฿25,000 แพงเกิน แต่ Tinder ห่วยเกิน"*

**moat ที่คู่แข่งลอกไม่ได้:** ข้อมูล **show-up rate** จาก QR ยืนยันการเจอ 2 ฝ่าย — ไม่มีเจ้าไหนวัดได้เพราะไม่มีข้อมูลการเจอจริง
คำขายคือ *"ที่นี่คุณจะเจอแต่คนที่มาตามนัดจริง"* ไม่ใช่ *"คุณอยู่เกรด 8"* → พูดออกสื่อได้ ไม่กลัวหลุด

### ความจริงที่ไม่กลบ
ธุรกิจนี้คือ**บริการ** เวลาเจ้าของคือต้นทุน · cold-start ฝั่งหญิงคือตัวฆ่าอันดับ 1 · PDPA (ข้อมูลรายได้/orientation) + เก็บเงินหลักหมื่น = ต้องคิดใบเสร็จ/ภาษี
