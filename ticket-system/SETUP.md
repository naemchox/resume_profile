# ติดตั้ง Ticket System by New-Gen

ไฟล์ในโฟลเดอร์นี้
- `index.html` — หน้าเว็บ (อัปขึ้น Netlify)
- `Code.gs` — ตัวกลางเชื่อมชีต (วางใน Apps Script)
- `TIcket_System.md` — แผนเดิม

ชีตที่ใช้: https://docs.google.com/spreadsheets/d/REPLACE_WITH_YOUR_SHEET_ID/edit
(ID นี้ใส่ไว้ใน `Code.gs` บรรทัด `SHEET_ID` แล้ว)

## 1. ติดตั้ง Apps Script (ทำครั้งเดียว ~5 นาที)

1. เปิดชีต → เมนู **Extensions → Apps Script**
2. ลบโค้ดเดิมใน `Code.gs` ทิ้ง แล้ววางเนื้อหาไฟล์ `Code.gs` ทั้งไฟล์ → กด 💾 Save
3. ช่องเลือกฟังก์ชันด้านบน เลือก **setup** → กด **Run**
   - ครั้งแรกจะขอสิทธิ์ → Review permissions → เลือกบัญชี → Advanced → Go to … (unsafe) → Allow
   - ดูที่ **Execution log** จะเห็น `รหัสทีมคือ: NG-XXXXXX` ← จดไว้ แจกให้ทีม
   - ในชีตจะมี 3 แท็บ: `Tasks`, `Users`, `Comments` พร้อมหัวคอลัมน์
4. (ไม่บังคับ) แท็บ **Users** — ไม่ต้องพิมพ์รายชื่อเอง ทีมลงทะเบียนชื่อตัวเองได้จากหน้าเว็บ
   แต่ถ้าอยากใส่ล่วงหน้าก็พิมพ์ได้ 1 คนต่อ 1 แถว (User ID, Name, Role, Email) ชื่อห้ามซ้ำกัน
5. กลับมาที่ Apps Script → **Deploy → New deployment**
   - กดเฟือง ⚙ → เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy → คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

## 2. ใส่ URL ลงหน้าเว็บ

เปิด `index.html` หาบรรทัดนี้ (อยู่ด้านบน)

```js
const DEFAULT_API_URL = '';
```

วาง URL ระหว่าง `''` แล้วเซฟ → ทีมจะไม่ต้องกรอก URL เอง
(ถ้าเว้นว่างไว้ หน้าเข้าสู่ระบบจะมีช่องให้กรอก URL แทน)

## 3. อัปขึ้น Netlify

1. เข้า https://app.netlify.com/drop
2. ลาก **โฟลเดอร์** ที่มีแค่ `index.html` ไปวาง (อย่าลากทั้งโฟลเดอร์นี้ เพราะจะติด `Code.gs` กับไฟล์แผนไปด้วย)
3. ได้ลิงก์ `xxxx.netlify.app` → Site settings → เปลี่ยนชื่อได้ เช่น `newgen-tickets`

## 4. แจกให้ทีม

ส่ง 2 อย่าง: **ลิงก์ Netlify** + **รหัสทีม** → เข้าเว็บ ใส่รหัส → เลือกชื่อตัวเอง
คนใหม่ที่ยังไม่มีชื่อ กด **"ไม่เจอชื่อ? ลงทะเบียนตัวเอง"** → กรอกชื่อ/ตำแหน่ง/อีเมล → เข้าใช้ได้ทันที (ชื่อถูกเพิ่มลงแท็บ Users อัตโนมัติ)

**พนักงานใหม่ไม่ต้องแตะ Apps Script หรือชีตเลย** — Apps Script ติดตั้งครั้งเดียวโดยแอดมิน

## ใช้งานประจำวัน

| อยากทำ | วิธี |
|---|---|
| สร้างงาน | ปุ่ม "สร้างงาน" (มุมซ้ายบน) หรือกด `C` · ปุ่ม + ข้างชื่อสถานะ = สร้างในสถานะนั้น |
| เปลี่ยนสถานะ | ลากการ์ดในบอร์ด หรือเปิดงานแล้วเปลี่ยนที่แผงขวา (บันทึกทันที) |
| ค้นหา | กด `/` |
| สลับมุมมอง | `1` ทุกงาน · `2` บอร์ด · `3` สรุปทีม · กดชื่อคนในแถบซ้ายเพื่อดูงานของคนนั้น |
| งานของฉัน | กด `M` |
| ลบงาน | เปิดงาน → "ลบ" มุมขวาบน → กดซ้ำภายใน 4 วิ (ลบถาวร พร้อมคอมเมนต์) |
| ส่งลิงก์งานให้เพื่อน | เปิดงาน → ไอคอน 🔗 (ลิงก์แบบ `…/#TIK-012`) |
| ออกจากระบบ | ไอคอนประตูข้างชื่อ (ซ้ายล่าง) กด 2 ครั้ง |
| โหมดสว่าง/มืด | ปุ่มซ้ายล่าง (เริ่มต้น = สว่าง) |

ข้อมูลซิงก์อัตโนมัติทุก 60 วินาที (หรือกด `R`)

## ดูแลระบบ

- **เปลี่ยนรหัสทีม:** Apps Script → ⚙ Project Settings → Script Properties → แก้ `TEAM_PASSCODE` → ทุกคนจะถูกให้ล็อกอินใหม่
- **แก้ `Code.gs` ภายหลัง:** Deploy → **Manage deployments** → ✏ → Version: **New version** → Deploy (URL เดิมใช้ต่อได้ ไม่ต้องแก้ index.html) — ถ้ากด New deployment จะได้ URL ใหม่
- **เพิ่มคน:** ให้ลงทะเบียนเองจากหน้าเว็บ · **ลบคน/แก้ชื่อ:** แก้แท็บ Users ได้เลย (คนที่ออกแล้ว ลบแถวทิ้ง + เปลี่ยนรหัสทีมถ้าไม่อยากให้เข้าได้อีก)
- **ห้ามเปลี่ยนชื่อแท็บหรือหัวคอลัมน์ในชีต** (สลับลำดับคอลัมน์ได้ ระบบอ่านจากชื่อหัว)
- `LAST_TASK_NUM` ใน Script Properties คือเลข TIK ล่าสุด — ระบบจัดการเอง กันเลขซ้ำหลังลบงาน

## ข้อจำกัด

- โหลด/บันทึกใช้เวลา ~1–3 วินาที (ความเร็ว Apps Script)
- ถ้าสองคนแก้งานเดียวกันพร้อมกัน คนที่บันทึกทีหลังจะเจอข้อความ "มีคนแก้งานนี้ไปก่อน" แล้วระบบโหลดข้อมูลล่าสุดให้ ไม่มีการเขียนทับกัน
- รหัสทีมกันคนนอกได้ระดับหนึ่ง แต่ไม่ใช่ระบบล็อกอินรายคน — คนในทีมเลือกชื่อคนอื่นได้
- เหมาะกับทีมไม่เกิน ~20 คน / งานไม่เกินหลักพันรายการ
