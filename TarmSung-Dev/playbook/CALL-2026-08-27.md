## ถ้าคนรับสายไม่ใช่เจ้าของ (แอดมิน/เคาน์เตอร์รับสาย) — เกิดแน่นอนกับคลินิก

คนรับสายคลินิกคือแอดมิน/พยาบาลหน้าเคาน์เตอร์ หน้าที่เขาคือ**นัดคิวคนไข้** และ**กันคนขายของ**
เจ้าของ = หมอ ซึ่งอยู่ในห้องหัตถการ ไม่รับสายแปลกอยู่แล้ว → อย่าตั้งเป้าว่าจะได้คุยเจ้าของในสายแรก

**เป้าของสายแรก = ได้ 2 อย่างเท่านั้น: ชื่อคนตัดสินใจ + เวลาที่โทรกลับได้** (ไม่ใช่ขายเว็บ)

### ท่าที่ 1 — อย่าถามหา "เจ้าของ" ให้ถามหาคนดูแลแอด
```
"สวัสดีครับ รบกวนถามครับ ตอนนี้ใครดูแลเรื่องยิงโฆษณาเฟซบุ๊กของคลินิกครับ?
ผมทำหน้าเว็บรับคนจากโฆษณาให้คลินิก มีเรื่องจะฝากถึงคนนั้นสั้นๆ ครับ"
```
คำว่า "เจ้าของ" = สัญญาณขายของ โดนตัดทันที · "คนดูแลโฆษณา" = คำถามงาน แอดมินตอบง่ายกว่ามาก
และคนดูแลแอด = คนที่ถือกระเป๋าเงินค่าโฆษณาอยู่แล้ว = คนที่เจ็บกับเรื่องนี้จริง

### ท่าที่ 2 — ถามชื่อคนตัดสินใจก่อนวางสายเสมอ
```
"ไม่เป็นไรครับ รบกวนถามชื่อคนที่ดูแลไว้หน่อยได้ไหมครับ จะได้ถามถูกคนตอนโทรกลับ
แล้วช่วงไหนเขาว่างที่สุดครับ?"
```
ได้ชื่อ = สายที่สองเปลี่ยนจาก "คนแปลกหน้าโทรขายของ" เป็น **"ขอเรียนสายคุณ___ ครับ"** ซึ่งโดนต่อสายบ่อยกว่าหลายเท่า

**ทางลัดหาชื่อโดยไม่ต้องถาม:** คลินิก/หจก. ที่จดทะเบียนบริษัทมีชื่อกรรมการเปิดสาธารณะบน `dataforthai.com`
(เช่นค้นวันนี้ J-Property Home เชียงใหม่ = คุณศิรัญญา ชัยวงศ์ / คุณวิวัฒน์ชัย ปันแจ่ม) — เสิร์ชชื่อร้าน + dataforthai ก่อนโทร 20 วินาที

### ท่าที่ 3 — ทิ้งของไว้ให้แอดมินส่งต่อ (แอดมินไม่จำคำพูด แต่ส่งลิงก์ต่อได้)
```
"ได้ครับ งั้นรบกวนฝากลิงก์เดียวให้เขาดูได้ไหมครับ ผมส่งเข้าไลน์คลินิกก็ได้
เป็นตัวอย่างหน้าเว็บคลินิกที่ผมทำ ดู 1 นาทีจบ ถ้าเขาสนใจค่อยให้ติดต่อกลับครับ"
```
