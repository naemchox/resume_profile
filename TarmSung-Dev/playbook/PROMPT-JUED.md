## แก่นของสูตร (4 ชั้น)

1. **AUDIT ก่อนเพิ่ม** — ความจืดส่วนใหญ่ไม่ได้มาจาก "ของน้อย" แต่มาจากของตกแต่งที่ประกาศไว้ใน CSS
   แล้วตั้งค่าจางจนไม่เคยขึ้นจอ (alpha .03–.10 ใต้ blur 60px, stroke 0.5px, เงาที่มองไม่เห็น)
2. **มาร์กที่ใช้ใหญ่** — อัตลักษณ์แบรนด์ใช้เป็น "ภาพ" ขนาดใหญ่ ไม่ใช่ไอคอน 24px
3. **motion ที่เป็นของงานนี้เท่านั้น** — ห้าม fade ทั่วไป ต้องหยิบจากภาษาของสินค้า/ธุรกิจนั้นจริงๆ
4. **ตัวเลขที่วิ่งมา** — ตัวเลขที่ยืนยันได้ต้อง count-up ไม่ใช่นั่งเฉย (ห้ามคิดตัวเลขเอง)

## พรอมป์ (ก๊อปทั้งบล็อก แล้วแก้ `[[ ]]`)

```
อ่าน [[ไฟล์เว็บ]] และ [[FACTS.md ถ้ามี]] ให้จบก่อน

ปัญหา: หน้าเว็บอ่านแล้วแบน — ทุก section เป็น eyebrow / หัวข้อ / grid ชุดเดียวกันซ้ำ
ไล่ลงไปเรื่อยๆ งานคือทำให้มันมีน้ำหนักและมีชีวิต โดยไม่แตะ "ข้อเท็จจริง" และไม่แตะ stack

ข้อห้าม (ผิดข้อไหนถือว่างานไม่ผ่าน)
- คง stack เดิมเป๊ะ: [[เช่น index.html ไฟล์เดียว ไม่มี npm/build/React]] ไม่โหลด JS lib ใหม่จาก CDN
  motion เขียนเองด้วย CSS + Web Animations/rAF เท่านั้น
- ห้ามเพิ่ม/แก้/ตีความข้อความที่เป็นข้อเท็จจริง ทุกคำต้องสืบกลับได้
  ไม่มีรีวิวปลอม ไม่มีจำนวนลูกค้า/ปีประสบการณ์/ยอดขาย ที่ไม่ได้ยืนยัน
- ห้ามเปลี่ยน layout/สี/ฟอนต์ที่ตกลงไว้แล้วเป็นแนวอื่น — งานนี้คือ "เร่งไฟให้ของที่มี"
  ไม่ใช่รีดีไซน์ ถ้าจะเปลี่ยนอะไรที่เห็นชัด ให้เสนอก่อน

ทำ 4 ชั้นนี้
1. AUDIT ก่อนเพิ่ม — ไล่ CSS หาของตกแต่งที่ประกาศไว้แล้วแต่จางจนไม่ปรากฏบนจอจริง
   (alpha ต่ำใต้ blur หนา, เงา/เส้น/texture ที่มองไม่เห็น) รายงานเป็นลิสต์ว่าเจออะไรบ้าง
   แล้วเร่งค่าให้มันทำงานจริง — ส่วนใหญ่ความจืดมาจากตรงนี้ ไม่ใช่เพราะของน้อย
   เช็ค contrast จริงเป็นตัวเลขด้วย (large text >= 3:1, ตัวเล็ก >= 4.5:1)
2. มาร์กที่ใช้ใหญ่ — เอาอัตลักษณ์ [[แบรนด์]] มาใช้ใหญ่เป็นภาพ ไม่ใช่ไอคอนเล็กๆ
   ซ้อนกับภาพหลักแบบ blend
3. motion ที่เป็นของ [[ธุรกิจนี้]] เท่านั้น — ไม่เอา fade ทั่วไป เลือกจากภาษาของงานนี้:
   [[ลิสต์ 4-6 อย่างที่มาจากตัวสินค้าจริง]]
   หัวข้อ section ให้ขึ้นทีละคำจาก clip-path mask (ต้อง copy ออกมาเป็นประโยคปกติได้)
   เส้นคั่นใต้หัวข้อให้ "วาด" ด้วย SVG stroke-dashoffset ไม่ใช่ border-bottom
4. ตัวเลขที่วิ่งมา — เฉพาะตัวเลขที่ยืนยันได้ (ราคา/ชั่วโมง/สเปก)
   ถ้าไม่มีตัวเลขให้เล่นเลย ห้ามคิดขึ้นมาเอง — ให้บอกกลับมาว่าต้องขออะไรจากลูกค้าบ้าง

กติกาเทคนิค
- ทุก reveal ยิงด้วย IntersectionObserver ห้ามผูกกับ scroll event
  (ของบนจอแรกจะไม่ทำงานเลยสำหรับคนที่เปิดมาแล้วไม่เลื่อน และมันจะรอดตอนเทสด้วยมือ)
- state ตั้งต้นของ animation อยู่ใน CSS, ค่าที่ script คำนวณให้ส่งเป็น px ไม่ใช่ %
- .reveal ที่ตั้ง opacity:0 ต้อง gate ไว้ใต้ html.js — ปิด JS แล้วหน้าต้องไม่ขาว
- prefers-reduced-motion ต้องปิดได้จริงทั้งฝั่ง CSS และฝั่ง JS (JS ต้อง set ค่าปลายทางเอง)
- ทุกอย่างต้องรันบน compositor ได้ (transform/opacity) ห้ามอนิเมต layout property
- will-change ปลดทิ้งเมื่อ animation จบ ห้ามค้างไว้ทุก section
- มือถือต้องไม่กระตุก เทสที่ 360px ด้วย

ส่งงาน: สรุปเป็นตารางว่าแก้อะไรไปบ้าง / อันไหนคือ "เร่งของเดิม" อันไหนคือ "ของใหม่"
และลิสต์สิ่งที่ต้องขอจากลูกค้าก่อนขึ้นจริง
```
