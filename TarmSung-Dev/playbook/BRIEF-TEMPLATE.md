### B1. Concept — metaphor เดียว ที่งอกจากชื่อหรือจากงานที่เขาทำ

> เขียนให้จบใน 2-3 ประโยค: ธุรกิจนี้เป็น **อะไร** และเว็บทั้งใบเดินตามจังหวะไหน

**เกณฑ์ผ่าน:** อ่านแล้วต้องตอบได้ว่า "ถ้าเปลี่ยนเป็นธุรกิจอื่น metaphor นี้พังไหม" — ถ้าไม่พัง แปลว่ามันยังไม่ใช่ metaphor ของแบรนด์นี้ ให้คิดใหม่
**เกณฑ์ตก:** metaphor ที่แปะเข้าไปเพราะดูเท่ (ครัว/อวกาศ/เกม) โดยที่ธุรกิจไม่ได้เกี่ยวอะไรด้วย = **คอสตูม** คนดูจับได้ทันที และแย่กว่า template เปล่าๆ

## ตัวอย่างที่กรอกแล้ว — ตามสั่ง (TarmSung)

| หัวข้อ | คำตอบ |
|---|---|
| ชื่อแบรนด์ | ตามสั่ง (TarmSung) |
| ชื่อนี้แปลว่าอะไร | "สั่งอะไรก็ทำให้" — คำที่คนไทยใช้กับร้านอาหารตามสั่ง |
| ขายอะไร | รับทำเว็บไซต์ เว็บแอป โมบายแอป |
| ลูกค้า | SME ไทย เจ้าของกิจการตัดสินใจเอง |
| อยากให้กดอะไรก่อน | ปุ่มปรึกษาฟรี → ฟอร์ม |

**B1 Concept:** ครัวตามสั่ง — ลูกค้าเขียนออเดอร์ → ครัวรับ → ปรุง → เสิร์ฟ เว็บทั้งใบเดินตามลำดับนั้น
*ทำไมผ่านเกณฑ์:* ชื่อแบรนด์แปลว่าตามสั่งอยู่แล้ว metaphor งอกจากชื่อ ไม่ได้แปะ — ย้ายไปคลินิกหรือเต็นท์รถแล้วพังทันที นั่นแหละคือข้อพิสูจน์ว่ามันเป็นของแบรนด์นี้

**B2 Palette:** ember ส้มไฟ (ไฟในเตา) / charcoal อุ่น hue 50 (ถ่าน+ไม้) / leaf เขียวใบตอง เฉพาะ success / วัสดุ = กระดาษใบสั่ง → grain + radius คม + เงา hard offset เหมือนหมึกพิมพ์ทับกระดาษ

**B3 โครงหน้า:** คำถามในหัวเจ้าของกิจการ SME คือ *ทำเว็บทำไม → ทำอะไรได้บ้าง → ทำแล้วดีจริงไหม → ใครทำ → นานแค่ไหน → เท่าไหร่ → ถามเพิ่มได้ไหม* จึงเรียงเป็น เมนู / ทีมในครัว / ขั้นตอนในครัว / เสิร์ฟไปแล้ว / ใบออเดอร์ราคา / ใบสั่งงาน / closer = `SERVED`
*ข้อควรระวังจากงานนี้:* โครงข้างบนเป็นของ**ธุรกิจรับจ้างทำของ** ที่ลูกค้าต้องเลือกผู้รับเหมา — พอเอาโครงเดียวกันไปใส่ร้านซ่อมนาฬิกา (ลูกค้ากลัวโดนสับอะไหล่ ไม่ได้กำลังเลือกซัพพลายเออร์) มันผิดตั้งแต่ลำดับแรก ดู B3.1 ก่อนเสมอ

**B4 Signature:** เลขคิวก้านตั๋วใน hero · ใบราคาฉีกได้ (perforation + notch) · การ์ดผลงาน hover แล้วยกฝาชี · `SERVED` เลื่อนขึ้นมาจากใต้ขอบเหมือนจานยกขึ้นที่ pass
