**เครื่องมือ** — `node playbook/make-icons.mjs <ไฟล์> [--write]`
ยุบไอคอนที่ซ้ำ ≥2 ครั้งให้เหลือ `<symbol>` ชุดเดียวแล้วเรียกด้วย `<use>` · เก็บแอตทริบิวต์เดิมของ `<svg>`
ไว้ครบ ภาพที่เรนเดอร์ออกมาจึงเหมือนเดิมเป๊ะ · รันซ้ำได้ไม่พัง (เจอ sprite แล้วจะข้าม)

> ไม่ได้กำหนดขนาดจะกางเป็นขนาดปริยาย 300×150 · เก็บ viewBox ไว้ทั้งหมดคือคำตอบ

**กฎที่ต้องผ่านทุกหน้าตั้งแต่นี้ไป**
1. **ไอคอนที่ใช้เกิน 1 ครั้งในหน้า = ต้องอยู่ใน sprite** ห้ามวาง `<path>` ซ้ำ · ตัวที่ใช้ครั้งเดียวปล่อยไว้ที่เดิมได้
2. **หนึ่งเว็บ = หนึ่ง sprite** วางไว้ต้น `<body>` · ตั้ง id ให้อ่านออก (`i-check` ไม่ใช่ `i-1`)
3. **ไอคอน UI ต้องเป็น SVG ห้ามใช้อีโมจิแทน** — อีโมจิใช้ได้เฉพาะเป็น "ตัวละคร/ภาพประกอบ" (อวตารทีม เป็ด Fastwork)
   และต้องเป็นไฟล์ Noto ที่โฮสต์เองใน `assets/emoji/` เท่านั้น ห้ามพึ่งอีโมจิของเครื่องผู้ใช้ (หน้าตาต่างกันทุก OS)
4. **รูปทุกใบต้องมีครบ 4 อย่าง**: `alt` ที่บอกว่าเห็นอะไร (ไม่ใช่ชื่อไฟล์) · `width`+`height` กัน layout กระโดด ·
   `.webp` · `loading="lazy"` ยกเว้นรูปแรกที่เห็นทันทีตอนเปิดหน้า
5. **รูปต้องอยู่ในโดเมนตัวเอง** — `playbook/deploy.mjs` มีด่านห้ามรูปจากเซิร์ฟเวอร์คนอื่นอยู่แล้ว (เคยหลุดมาแล้ว
   กับ `c2.hongpak.in.th`) · โหลดมาเก็บในโฟลเดอร์ของเดโมเอง ห้าม hotlink
6. **หารูปสินค้าจริงได้ ถ้าเป็นรูปถ่ายจากคลังภาพฟรี** — Unsplash License อนุญาตให้ใช้เชิงพาณิชย์
   ไม่บังคับเครดิต · วิธีทำ: `WebSearch` หาหน้ารูป → `WebFetch` ขอ URL ที่ขึ้นต้น `images.unsplash.com/photo-`
   → `curl -sL -o <ไฟล์> "<url>?w=900&q=75&fm=jpg"` → แปลงเป็น webp ด้วย ffmpeg ที่ติดมากับรีโป
   → เขียนที่มาลง `img/CREDITS.md` ของเดโมนั้น (ดูตัวอย่างที่ `work/gamedock/img/CREDITS.md`)
   > ⚠️ **ต้องเปิดรูปดูก่อนใช้ทุกใบ** — รอบแรกได้รูปหลังเครื่อง Switch Lite ขาวดำมาแทน Switch OLED
   > และได้แว่น Oculus มาใส่การ์ดที่เขียนว่า "ชุด VR สำหรับ PS5" ต้องแก้ชื่อสินค้าให้ตรงกับรูป
   > ไม่ใช่ปล่อยให้รูปกับข้อความขัดกัน
7. **เส้นแบ่งว่าอันไหนหาได้ อันไหนต้องวาดเอง**
   - รูป **ถ่าย** ของอุปกรณ์ที่วางขายทั่วไป (เครื่องเกม จอ เก้าอี้ อาหาร) → คลังภาพฟรีมี ใช้ได้
   - งาน **ออกแบบ** ของคนอื่น (ปกเกม โลโก้ ตัวละคร บรรจุภัณฑ์) → **ห้ามแตะ** ไม่มีคลังภาพฟรีเจ้าไหนแจก

   แต่ **รูปถ่ายบรรยากาศตามแนวของเกม** ใช้ได้ เอามาย้อมสีประจำเกมแล้ววางชื่อเกมทับ = องค์ประกอบ

12. **เว็บหลายหน้าทุกใบต้องมี cross-document view transition** — `@view-transition { navigation: auto; }`

    **นี่คือของที่แพ็ก ฿7,500 ขาย** — เว็บหน้าเดียวไม่มีรอยต่อระหว่างหน้าให้เห็น เว็บหลายหน้ามี

    "ทำงานได้บางจุด" คือรูปแบบของบั๊กนี้ ไม่ใช่ข้อยกเว้น
15. **ทั้งสองข้อต้องถอยให้ `prefers-reduced-motion: reduce`** — VT ปิดอนิเมชัน, `.is-leaving` ไม่จาง

ตรวจตอนไม่เลื่อน = ผ่านทุกครั้ง นี่คือเหตุผลที่มันรอดมาถึงตาคน

### กฎที่ตั้ง

16. **วัดของที่ตาเห็น ไม่ใช่ของที่ผังบอก** — อะไรที่มี `transform` (rotate/scale/skew) ห้ามเชื่อ
    `offsetHeight`/`offsetWidth` ต้องเทียบด้วย `getBoundingClientRect()` เสมอ
17. **แถบเมนูที่หดได้ ต้องตรวจ "ตอนหดแล้ว"** — ตอนหดคือตอนเตี้ยที่สุด = ตอนที่ของเกย
    ด่านไหนตรวจแค่ตอนโหลดหน้า ด่านนั้นไม่ได้ตรวจอาการนี้เลย
18. **แถบที่หดแล้วต้องไม่เตี้ยกว่ากล่องที่ตาเห็นของลูกที่สูงที่สุด** — บังคับด้วยพื้นความสูงขั้นต่ำ
    (`header.small > * { padding-block: 10px }`) ไม่ใช่ปล่อยให้หดจนชนกัน
19. **หด `padding` ของลูก ห้ามสั่ง `height` ของแถบ** — กฎนี้ตั้งไว้แล้วเมื่อ 22 ส.ค. แต่ยังทำไม่ครบ
    ดูหนี้ข้างล่าง · สั่ง `height` แล้วลูกที่ตั้ง `height` ตายตัวจะไม่หดตาม แถบเตี้ยกว่าลูก = เกยทันที
