# ส่งมอบงานลูกค้า — ลำดับที่ต้องทำทุกครั้ง

เขียนไว้ก่อนมีลูกค้ารายแรก เพราะขั้นตอนที่คิดสดตอนลูกค้ารออยู่ = ตกหล่นแน่นอน

---

## 1. จากเดโม → เว็บของลูกค้า

```bash
node playbook/new-client.mjs <เดโมต้นแบบ> <slug> "ชื่อร้าน" [เบอร์] [ไลน์]
```
สคริปต์ก๊อปโฟลเดอร์ + แทนชื่อ/เบอร์/ไลน์ให้ แล้วสแกนซ้ำว่าไม่มีของต้นแบบหลงเหลือ

**งานที่คนต้องทำต่อ** (สคริปต์ทำแทนไม่ได้)
- [ ] รูปจริงของร้าน วางทับใน `work/<slug>/img/` โดยใช้ชื่อไฟล์เดิม
- [ ] เนื้อหาจริง: เมนู/บริการ/ราคา/เวลาเปิด/ที่อยู่/เบอร์
- [ ] **ลบ `<meta name="robots" content="noindex,nofollow">` ออก** — อันนี้มีไว้สำหรับเดโมเท่านั้น เว็บลูกค้าต้องให้ Google เก็บ
- [ ] แทนที่ทุกจุดที่ยังเป็น `xx` (เบอร์/เลขซอย) ด้วยของจริงของลูกค้า

## 2. ด่านตรวจก่อนส่ง

```bash
node playbook/deploy-client.mjs <slug> --dry
```
ด่านนี้ไม่ให้ผ่านถ้ายังมี: `noindex` · ข้อมูลที่ยังเป็น `xx` · ชื่อร้านของเดโมต้นแบบหลงเหลือ
(ข้อสุดท้ายคือความผิดพลาดที่แพงที่สุดตอนส่งงาน — ลูกค้าเปิดมาเจอชื่อร้านคนอื่น)

## 3. ปล่อยขึ้นเว็บ

```bash
node playbook/deploy-client.mjs <slug>
```
ได้ `https://client-<slug>.pages.dev` เป็นโปรเจกต์แยกของลูกค้าเอง **ไม่ใช่** ใต้ `/work/` ของเรา
เพราะเว็บลูกค้าต้องย้ายไปโดเมนตัวเองได้โดยไม่กระทบเว็บเรา และต้องให้ค้นเจอ (ตรงข้ามกับเดโม)

**ต่อโดเมนของลูกค้า:** Cloudflare → Pages → `client-<slug>` → Custom domains
ถ้าลูกค้ายังไม่มีโดเมน ใช้ `.pages.dev` ไปก่อนได้ ไม่มีค่าใช้จ่าย

## 4. ขอรีวิว — ทำทันทีวันส่งมอบ ไม่ใช่สัปดาห์หน้า

คนไม่ชอบเขียนเอง ให้ร่างไปให้แก้ 2-3 คำ:

```
ทักไปพร้อมลิงก์เว็บ:

พี่ครับ เว็บเสร็จแล้วนะครับ [ลิงก์]
รบกวนพี่ช่วยรีวิวสั้นๆ ให้ผมหน่อยได้ไหมครับ ผมร่างไว้ให้แล้ว พี่แก้ให้ตรงกับที่รู้สึกจริงได้เลย

"ทำเว็บให้ร้านเรา คุยง่าย ทำให้ดูก่อนตัดสินใจ ไม่ต้องมัดจำ
งานเสร็จตามที่บอกไว้ ตอนนี้ลูกค้าเห็นเมนูกับเวลาเปิดจากในเว็บได้เลย ไม่ต้องทักมาถามซ้ำ"
```

**เอาไปวางที่ไหน**
- [ ] ประกาศ Fastwork (ถ้าลูกค้ามาจาก Fastwork ให้กดรีวิวในระบบ = มีน้ำหนักที่สุด)
- [ ] การ์ดผลงานในเว็บเรา — เปลี่ยนป้าย "แบรนด์สมมติ" เป็นชื่อลูกค้าจริง + ลิงก์เว็บจริง
- [ ] ถ่ายภาพ/คลิปเข้าพอร์ต: เพิ่ม slug ในลิสต์ของ `shoot-cover.mjs` และ `shoot-pages.mjs` แล้วรัน

## 5. สิ่งที่ต้องบอกลูกค้าเป็นลายลักษณ์อักษร (กันปัญหาทีหลัง)

- ซอร์สโค้ดและระบบเป็นของลูกค้าเมื่อจ่ายเงินครบแล้ว ย้ายผู้ดูแลได้อิสระ
- รับประกันงานเสีย: หน้าเดียว 1 เดือน · แพ็กเกจอื่น 3 เดือน (ต้องตรงกับที่เขียนบนเว็บ)
- รอบแก้ที่ให้มากับแพ็กเกจ = ปรับงานในขอบเขตเดิม ไม่ใช่เปลี่ยนโจทย์ใหม่
- ค่าโดเมน/โฮสต์: ตอนนี้ฟรีบน Cloudflare Pages ถ้าลูกค้าอยากได้โดเมนตัวเอง มีค่าจดรายปีซึ่งลูกค้าจ่ายเอง
