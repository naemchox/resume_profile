เคสที่ราคาบอกล่วงหน้าไม่ได้ เราทำยังไง

ผ่าตัดและเคสฉุกเฉินไม่มีราคาตายตัวจริงๆ — แต่ "บอกไม่ได้" ไม่เท่ากับ "ไม่บอก"

  1. 1. ตรวจก่อน แล้วบอกช่วงราคา

    หมอตรวจเสร็จจะบอกว่าน่าจะอยู่ในช่วงเท่าไหร่ และอะไรที่ทำให้มันขยับขึ้น

  2. 2. คุณเซ็นก่อนเราลงมือ

    ไม่มีการทำก่อนแล้วค่อยบอกราคาทีหลัง แม้จะเป็นตี 3

  3. 3. ถ้าระหว่างทางจะเกินที่ตกลง เราหยุดแล้วโทรหาคุณ

    ยกเว้นกรณีเดียว — หยุดแล้วสัตว์จะเสียชีวิต เราจะทำต่อแล้วโทรบอกทันทีที่ทำได้

  4. 4. ใบเสร็จแยกรายการ

    ค่าหมอ ค่ายา ค่าห้อง ค่าเครื่องมือ แยกบรรทัดกัน ไม่ใช่ก้อนเดียวว่า "ค่ารักษา"
