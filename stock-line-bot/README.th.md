# Stock LINE Bot

บอท LINE แจ้งราคาหุ้น (ไทย + อเมริกา) ตามรอบเวลาที่ตั้ง รวมทุกตัวเป็นข้อความเดียว · ใช้ได้หลายคน แต่ละคนมีรายการหุ้นของตัวเอง
รันบน Cloudflare Workers (ฟรี) · ราคาจาก Yahoo Finance (ล่าช้า ~15 นาที)

## ทำงานยังไง
- ค่าเริ่มต้นแจ้งทุก 1 ชม. (ไทย+อเมริกา ≈ 264 ข้อความ/เดือน อยู่ในโควตาฟรี)
- Cron รันทุก 5 นาที → ถ้าตรงรอบที่ตั้ง (เช่น ทุกต้นชั่วโมงเวลาไทย) จะดึงราคาหุ้นทุกตัว
- ส่งเฉพาะหุ้นที่ **ตลาดเปิดอยู่และมีราคาใหม่** ตั้งแต่รอบที่แล้ว → วันหยุด พักเที่ยง กลางคืน ไม่ส่ง ไม่เสียโควตา
- ก่อน push เช็กโควตา LINE ถ้าหมดแล้วจะไม่ส่ง (คำสั่ง `ราคา` ยังใช้ได้ เพราะเป็น reply ไม่นับโควตา)
- คนแรกที่ทักบอทจะเป็นเจ้าของ (เห็นโควตารวม + คำสั่ง `ผู้ใช้`)

## หลายผู้ใช้ + แบ่งโควตา
- ได้แจ้งเตือนอัตโนมัติสูงสุด **2 คน** (รวมเจ้าของ) — `MAX_PUSH_USERS` ใน `src/schedule.ts`
- คนที่ 3 เป็นต้นไปใช้คำสั่งได้ทุกอย่าง (เช่น `ราคา` ฟรี) แต่ไม่ได้แจ้งเตือนอัตโนมัติ
- ใครบล็อกบอท จะคืนที่ให้ — คนที่รออยู่จะได้ที่เมื่อทักบอทครั้งถัดไป
- โควตา 300 × 90% = 270 หารเท่ากันตามคนที่ **กำลังรับอยู่** (ไม่นับคนที่ `หยุด` หรือยังไม่มีหุ้น)
- ถ้ารอบที่ตั้งเกินส่วนแบ่ง ระบบยืดรอบให้เอง (15/30/45 นาที, 1/1.5/2/3/4/6/8/12/24 ชม.) และบอกในคำสั่ง `รายการ`/`รอบ`
  - ตัวอย่าง ไทย+อเมริกา: 1 คน → ทุก 1 ชม. · 2 คน → ทุก 3 ชม.
- ข้อมูลใน KV: `meta` (เจ้าของ, คนที่ได้แจ้งเตือน, คนที่รอ) + `user:<userId>` (หุ้น/รอบ/หยุด ของแต่ละคน) · key `state` เดิมถูกย้ายเข้าโครงใหม่อัตโนมัติ

## คำสั่งในแชท
| คำสั่ง | ทำอะไร |
|---|---|
| `เพิ่ม PTT AAPL` | เพิ่มหุ้น (ไทยไม่ต้องใส่ .BK, สูงสุด 20 ตัว) |
| `ลบ PTT` | เอาออก |
| `รายการ` | ดูหุ้นที่ติดตาม + ประมาณการข้อความ/เดือน |
| `รอบ 30` / `รอบ 1ชม` | ตั้งรอบ (ขั้นต่ำ 15 นาที, หาร 5 ลงตัว) |
| `ราคา` | ดูราคาตอนนี้ — ฟรี |
| `หยุด` / `เริ่ม` | พัก / เปิดแจ้งเตือน |
| `โควตา` | เจ้าของ: ยอดรวมทั้งบอท · คนอื่น: ส่วนแบ่งของตัวเอง |
| `ผู้ใช้` | (เฉพาะเจ้าของ) ดูว่าใครใช้อยู่ รอบจริงของแต่ละคน |
| `วิธีใช้` | ตัวอย่างการพิมพ์ทุกคำสั่ง (มีปุ่มลัดใต้แชท) |

## ติดตั้ง (ครั้งแรก)
1. **LINE**: สร้าง LINE Official Account → เปิด Messaging API → ไปที่ [LINE Developers Console](https://developers.line.biz/console/)
   - คัดลอก **Channel secret** (แท็บ Basic settings)
   - กด Issue **Channel access token (long-lived)** (แท็บ Messaging API)
   - ใน LINE OA Manager: ปิด *Auto-reply messages* และ *Greeting message* (ไม่งั้นบอทตอบซ้อน)
2. **Cloudflare**:
   ```bash
   npm install
   npx wrangler login
   npx wrangler kv namespace create STATE     # (ทำแล้ว: id อยู่ใน wrangler.toml)
   npx wrangler secret put LINE_CHANNEL_SECRET
   npx wrangler secret put LINE_CHANNEL_ACCESS_TOKEN
   npm run deploy
   ```
3. **ต่อ webhook**: ใน LINE Developers → Messaging API → Webhook URL = `https://stock-line-bot.<subdomain>.workers.dev/webhook` → กด Verify → เปิด *Use webhook*
4. เพิ่มเพื่อนบอท แล้วพิมพ์ `ช่วย` (คนแรกที่ทัก = เจ้าของ)

## ทดสอบในเครื่อง
สร้าง `.dev.vars`:
```
LINE_CHANNEL_SECRET=testsecret
LINE_CHANNEL_ACCESS_TOKEN=dry
```
`dry` = พิมพ์ข้อความที่จะส่งลง log แทนการส่งจริง แล้วรัน `npm run dev`
จำลอง cron: `curl "localhost:8787/__scheduled"` (ทำงานเฉพาะเมื่อเวลาจริงตรงรอบ)

## ข้อควรรู้
- โควตาฟรี LINE OA ไทย ~300 push/เดือน รีเซ็ตต้นเดือน ไม่ทบ
- ประมาณการ: ไทย+อเมริกา รอบ 30 นาที ≈ 528/เดือน (เกิน) · รอบ 1 ชม. ≈ 264 · ไทยอย่างเดียวรอบ 30 นาที ≈ 220
- Yahoo Finance เป็น API ไม่เป็นทางการ อาจเปลี่ยนหรือบล็อกได้ — ถ้าราคาไม่มา ดู log ด้วย `npx wrangler tail`
- รีเซ็ตเจ้าของ/รายชื่อผู้ใช้: `npx wrangler kv key delete --binding STATE meta --remote` (ข้อมูลหุ้นแต่ละคนอยู่ที่ `user:<id>`)
- ทดสอบรอบส่งในเครื่อง: `curl localhost:8787/__scheduled` ใช้เวลาจริงเสมอ (`?time=` ไม่มีผล) — ถ้าจะจำลองเวลา ให้แก้ `now` ชั่วคราวใน `runSchedule`
