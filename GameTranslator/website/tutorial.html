1เริ่มใช้ครั้งแรก — 3 ขั้น

ใช้เวลาไม่ถึง 2 นาที ทำครั้งเดียวจบ

ขั้นที่ 1 — เปิดแอป

Windows: เปิดไฟล์ Gloss-win.exe ที่โหลดมา → ติดตั้ง → เปิดจาก Start menu · ครั้งแรก Windows อาจขึ้น “Windows protected your PC” ให้กด More info → Run anyway (เพราะแอปยังไม่ได้ซื้อใบรับรอง ไม่ใช่เพราะมีอะไรผิดปกติ)

Mac: เปิดไฟล์ .dmg → ลาก Gloss ไปไว้ในโฟลเดอร์ Applications → เปิด · ครั้งแรกอาจต้องไปที่ System Settings → Privacy & Security → Open Anyway

ทั้งสองแบบ พอเปิดแล้วจะเห็น แคปซูลเล็กๆ ลอยอยู่ที่มุมจอ — นั่นคือตัวแอป มันลอยอยู่เหนือทุกอย่าง รวมถึงเกมแบบเต็มจอ

ขั้นที่ 2 — อนุญาตให้อ่านหน้าจอ (เฉพาะ Mac)

บน Windows ข้ามข้อนี้ไปเลย — ไม่ต้องตั้งสิทธิ์อะไรทั้งนั้น เปิดแล้วใช้ได้ทันที (ครั้งแรก Windows อาจเตือนว่าไม่รู้จักผู้พัฒนา กด More info → Run anyway ครั้งเดียวจบ)

บน macOS: ระบบจะถามหาสิทธิ์ Screen Recording — Gloss ต้องใช้เพื่อ “มองเห็น” ข้อความบนจอ · ไม่ได้อัดวิดีโอ ไม่ได้ส่งภาพหน้าจอไปไหน

ระวังจุดที่คนพลาดบ่อยที่สุด: macOS มีสองหน้าที่หน้าตาคล้ายกัน — Accessibility (คีย์ลัด) กับ Screen & System Audio Recording (อ่านหน้าจอ) · จุดแดงที่เขียนว่า “Screen off” หมายถึงอันหลัง · กดปุ่มในแอปให้มันพาไป จะไม่ไปผิดหน้า

ถ้าติ๊กแล้วยังไม่ติด: รายการนั้นผูกกับเวอร์ชันเก่า ให้ปิดสวิตช์แล้วเปิดใหม่ แล้วกด เปิด Gloss ใหม่ ในแอป

ขั้นที่ 3 — ลองลากดู

กดค้าง ⌃ ⌥ แล้วลากกรอบคลุมข้อความอังกฤษที่ไหนก็ได้บนจอ · ปล่อยมือ — คำแปลไทยจะเด้งขึ้นตรงนั้นเลย

24 วิธีให้ Gloss อ่านข้อความ

เลือกใช้ตามสถานการณ์ ไม่ต้องจำทั้งหมด — วิธีแรกวิธีเดียวก็ใช้ได้แล้ว 90%

① ลากกรอบ (Snip) — Ctrl+Alt ค้างแล้วลาก (Mac: ⌃⌥)

วิธีหลัก ใช้ได้กับทุกอย่างบนจอ: บทสนทนาในเกม, ป้ายในภาพ, PDF ที่ก๊อปไม่ได้, ปุ่มในโปรแกรม

ตั้งค่าได้ 2 แบบใน Settings — กดค้างแล้วลาก (ปล่อยแล้วแปลทันที) หรือ กดปุ่มก่อนแล้วค่อยลาก (มือว่างทั้งสองข้าง เล็งง่ายกว่า)

② พิมพ์เอง (Type) — Alt+T

รู้คำแล้วอยากรู้แปล พิมพ์ลงไปตรงๆ ไม่ต้องลากอะไร · เหมาะกับคำที่เห็นในหนังสือหรือได้ยินมา

③ พูดใส่ไมค์ (Speak) — Alt+M

พูดประโยคอังกฤษที่ได้ยินมา แล้วให้แปลเป็นไทย · ต้องอนุญาตไมโครโฟนครั้งแรก

④ ซับไตเติลสด (CC) — Alt+C

ใช้กับสิ่งที่ ข้อความเปลี่ยนไปเรื่อยๆ เช่นบทสนทนายาวๆ ในเกม หรือซับในวิดีโอ

วิธีใช้: กด “Choose subtitle area…” ใน Settings ครั้งเดียว → ลากกรอบคลุมบริเวณที่ข้อความจะโผล่ → จากนั้นทุกครั้งที่ข้อความในกรอบนั้นเปลี่ยน Gloss จะแปลให้อัตโนมัติ

ตั้งกรอบครั้งเดียวต่อ 1 เกม · เปิด-ปิด CC ทีหลังไม่ต้องตั้งใหม่ · ปรับความถี่ในการอ่านได้ที่ “CC speed”

3ปุ่มบนการ์ดคำแปล

พอคำแปลขึ้นมาแล้ว มุมขวาบนของการ์ดมีปุ่มเล็กๆ อยู่

ปุ่มทำอะไรใช้ตอนไหน
✦ให้ AI เขียนการ์ดแบบละเอียดอยากได้คำอ่าน · ความหมายลึก · รูปคำอื่นๆ · ประโยคตัวอย่าง
☆เก็บคำนี้เข้าคลังเจอคำที่อยากจำ — ไปทวนทีหลังในหน้าต่าง Learn
🔊อ่านออกเสียงอยากรู้ว่าออกเสียงยังไง
⚑บอกว่าอันนี้อ่านผิดอ่านเพี้ยนหรือแปลมั่ว — กดแล้วส่งถึงเราเลย ไม่ต้องเขียนอะไร
✕ปิดการ์ดหรือกด Ctrl+Shift+X (Mac: ⌘⇧X)
การ์ดจะไม่หายเอง — มันอยู่จนกว่าคุณจะปิดหรือแปลอันใหม่ · ตั้งใจให้เป็นแบบนี้ จะได้อ่านทันโดยไม่ต้องรีบ

4ชี้คำ — ดูความหมายทีละคำ

ฟีเจอร์ที่ตัวแปลทั่วไปไม่มี

กด Alt+G เพื่อเปิดโหมดชี้คำ แล้วเอาเมาส์ไปวางบนคำอังกฤษคำไหนก็ได้บนจอ — ความหมายของคำนั้นคำเดียวจะเด้งขึ้นมา

  • ใช้พจนานุกรม 77,000 คำ ที่อยู่ในเครื่อง — ไม่ต้องต่อเน็ต ไม่กินโควตา AI
  • เจอคำที่อยากเก็บ กด Alt+K เก็บเข้าคลังได้ทันที ไม่ต้องละสายตา
  • กด Alt+G อีกครั้งเพื่อปิดโหมด

ต่างจากการแปลทั้งประโยคตรงที่: ประโยคบอกว่า “รวมๆ แปลว่าอะไร” แต่การชี้คำบอกว่า “คำนี้แปลว่าอะไร” — อันหลังคือสิ่งที่ทำให้จำได้

7ตั้งค่าที่ควรรู้

เปิดด้วยไอคอนเฟืองบนแคปซูล (Mac กด ⌘, ก็ได้) — มี 4 แท็บ

Gameplay

ภาษา (อังกฤษ → ไทย) · ตั้งกรอบซับไตเติล · ความเร็ว CC · ระดับเสียงอ่านออกเสียง

Display

ขนาดการ์ด · หน้าตาแคปซูล (ชัด/จาง/โปร่ง/อยู่หลังหน้าต่างอื่น) · ซ่อนจากการอัดจอ — เปิดไว้แล้วแคปซูลจะไม่ติดในคลิปที่คุณอัดหรือสตรีม

Controls

ปุ่มลัดทั้งหมด · โหมดลากกรอบ (กดค้าง หรือ กดก่อนลาก) · เปิดแอปอัตโนมัติตอนเปิดเครื่อง

System

แจ้งปัญหา · แพลนและไลเซนส์ · ภาษาของตัวแอป · รีเซ็ตค่าทั้งหมด

9เจอปัญหา ทำยังไง

จุดแดง + ขึ้นว่า “Screen off” (Mac เท่านั้น)

macOS ยังไม่ให้สิทธิ์อ่านหน้าจอ · กดปุ่มในแอป → เปิด System Settings → ติ๊ก Gloss → กลับมากด “Reopen Gloss” (macOS บังคับให้เปิดแอปใหม่เสมอ)

เคยติ๊กแล้ว แต่ยังไม่ทำงาน (Mac เท่านั้น)

ถ้ารายการ Gloss ในลิสต์ยังเขียวอยู่ ให้ ปิดแล้วเปิดใหม่ — เวอร์ชันใหม่ของแอปต้องทำแบบนี้ครั้งหนึ่ง แม้สวิตช์จะดูเปิดอยู่แล้วก็ตาม

อ่านออกมาเพี้ยน

ลากกรอบให้ใหญ่ขึ้นอีกนิด หรือให้ชิดขอบข้อความน้อยลง · ถ้ายังเพี้ยนอีก กด ⚑ บนการ์ด — เราจะเห็นว่ามันอ่านอะไรผิด

แคปซูลบังเกม

กด Ctrl+Shift+L (Mac: ⌘⇧L) ล็อกไว้ — คลิกจะทะลุไปที่เกมทั้งหมด · หรือเปลี่ยนหน้าตาแคปซูลเป็นแบบจาง/โปร่ง ใน Settings › Display

ยังติดอยู่? กด Settings › System › Report a problem ในแอปแล้วเขียนมาได้เลย — แนบไปแค่เวอร์ชันแอป ระบบปฏิบัติการ และคู่ภาษา ไม่มีอย่างอื่น
