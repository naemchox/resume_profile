# Gloss — ลองแปลเกมให้หน่อย 🎮

แอปเล็กๆ ที่แปลข้อความในเกม (EN/JP/CN/KR → ไทย) แบบสดๆ ตอนเล่น
A tiny app that translates on-screen game text on the fly.

---

## เปิดครั้งแรก (Mac) — First open
แอปยังไม่ได้ sign → Mac จะเตือน "unidentified developer"
1. **คลิกขวา** ที่ Gloss.app → **Open** → **Open** (ทำครั้งเดียว)
2. อนุญาต **Screen Recording** ตอนถาม (System Settings → Privacy) แล้วเปิดแอปใหม่

## วิธีใช้ — How to use (มี pill เล็กๆ ลอยบนจอ)
1. เปิดเกม (หรือหน้าจอที่มีข้อความอ่านไม่ออก)
2. **กด Ctrl+Option (⌃⌥) ค้าง** แล้ว **ลากเมาส์คลุมข้อความ**
3. **ปล่อย** → การ์ดคำแปลเด้งขึ้นมา
   - หรือ: กด **⌘⇧S** แล้วลากกรอบ ก็ได้

*อย่าเพิ่งถามวิธี — ลองหาเองก่อน ถ้าหาไม่เจอ = นั่นแหละคือ feedback ที่ผมอยากรู้*
