# เช็คลิสต์เทส — Windows (อัปเดต 2026-07-25)

พอร์ตมาจาก macOS ยังไม่เคยเทสเต็มบน Windows เลย ติ๊ก ✅/❌ ไว้ เจอปัญหาจดข้างล่างข้อนั้น

## 0. ต้อง build บนเครื่อง Windows เท่านั้น (ทำจาก mac ไม่ได้)

ตรวจแล้ว 2026-07-25: สร้างตัวติดตั้ง Windows จาก macOS **ไม่ได้** เพราะ `uiohook-napi` (ดัก Ctrl+Alt)
และ `koffi` (เรียก user32/gdi32 ตอนแคปจอ) เป็น native module — binary ของ Windows สร้างข้ามเครื่องไม่ได้
และบนเครื่อง mac นี้ทั้งสองตัวไม่ได้ถูกติดตั้งด้วยซ้ำ

```
git clone https://github.com/monmon7735-coder/GameTranslator.git
cd GameTranslator
npm install            # ขั้นนี้แหละที่ดึง binary ฝั่ง Windows ลงมา
npm start              # ลองรันสดก่อน
npm run dist:win       # ได้ dist/Gloss Setup 1.0.0.exe
```

- [ ] `npm install` จบโดยไม่มี error เรื่อง build native module
- [ ] `node -e "require('uiohook-napi');require('koffi')"` โหลดผ่านทั้งคู่
- [ ] `npm start` เปิดแอปได้ ไม่มี MODULE_NOT_FOUND ใน console
- [ ] `npm run dist:win` ออกไฟล์ .exe ได้ และติดตั้งแล้วเปิดจาก Start Menu ได้
- [ ] ไฟล์ .exe ที่แนบใน GitHub Release ตอนนี้เป็นของ **16 ก.ค. = ก่อน merge พอร์ต Windows**
      → **ห้ามปล่อยตัวนั้น** ต้องแทนด้วยตัวที่ build ใหม่จากขั้นบนก่อน

## 1. ท่าหลัก: กด Ctrl+Alt ค้างแล้วลาก (คำถามใหญ่ที่สุด ยังไม่เคยรันบน Windows เลยสักครั้ง)

ตั้งแต่ 2026-07-20 ท่านี้คือท่าหลักของแอป (⌘⇧S / Ctrl+Shift+S เป็นตัวสำรอง) ทั้งหมดนี้ยังไม่มีใครพิสูจน์บน Windows

- [ ] กด Ctrl+Alt ค้าง → เคอร์เซอร์เปลี่ยนเป็นเป้า, ลากคลุมข้อความ, ปล่อย → แปลออก
- [ ] ระหว่างลาก **ห้าม**ไปคลิก/ลากโดนของในเกมหรือแอปข้างล่าง (WH_MOUSE_LL ต้องกลืน left-button)
- [ ] ปล่อยแล้วเมาส์กลับมาปกติทันที ไม่หน่วง ไม่ค้าง
- [ ] กดค้างแล้วเปลี่ยนใจ ไม่ลาก ปล่อยเฉยๆ → ไม่ควรมีอะไรเกิดขึ้น
- [ ] ทำรัวๆ 10 ครั้งติด → hook ไม่หลุด ไม่ต้องรีสตาร์ทแอป
- [ ] preview ระหว่างลากขึ้นทัน (บน Windows ตั้ง throttle ไว้ 260ms ช้ากว่า mac ที่ 180ms)
- [ ] ถ้า hook ติดตั้งไม่ได้ (สิทธิ์/แอนติไวรัส) → ต้องตกไป uiohook แบบ listen-only และบอกผู้ใช้ ไม่ใช่เงียบ
- [ ] เมาส์ปุ่มกลาง (middle-click) ตัดกรอบ ใช้ได้ไหม

## ✅ เทสแล้ว ผ่าน

- [x] แอปเปิดขึ้น, OCR worker พร้อม, ปุ่มลัดจดได้ครบ 6 ปุ่ม
- [x] Ctrl+Shift+S ติดอาวุธ snip, ลากกรอบได้, ปล่อยแล้วอ่าน
- [x] **ลากแล้วไม่ไฮไลต์ข้อความข้างล่างแล้ว** (WH_MOUSE_LL กลืน left-button)
- [x] เมาส์ไม่ lag หลังปล่อยลาก (เลิกเรียก `uIOhook.stop()` ต่อ snip)
- [x] แคป region ~15ms (เดิม 400ms)

## ⬜ ยังไม่เทส — ต้องมาไล่

### พื้นฐาน
- [ ] ใส่ API key แล้วแปลออกจริง (ตอนนี้ `settings.json` → `apiKey: ""` ยังว่าง)
- [ ] OCR อ่านแม่นแค่ไหนกับข้อความเกมจริง (ตัวเล็ก, พื้นหลังลาย, ตัวมีขอบ)
- [ ] การ์ดคำแปลขึ้นถูกตำแหน่ง อ่านง่าย หายเองตามเวลาที่ตั้ง (`holdSec`)
- [ ] snip ซ้ำๆ รัวๆ 5-10 ครั้งติด — มีอะไรค้าง/เพี้ยนไหม
- [ ] Esc ยกเลิกกลางลาก แล้ว snip ใหม่ได้ปกติ
- [ ] ลากกรอบเล็กมาก (จิ้มแล้วปล่อย) — ไม่ควรพัง ไม่ควรค้าง

### หน้าตา/การเคลื่อนไหวที่แก้ 2026-07-24 (พิสูจน์บน mac ด้วยการวัดแล้ว บน Windows ยังไม่เคยเห็น)

Windows วาดด้วย engine เดียวกัน (Chromium) แต่ backdrop-filter/scrollbar/DPI ต่างกัน จุดพวกนี้จึงต้องดูซ้ำ

- [ ] ข้อความเลื่อนในช่องขวาของ pill: **คำแปลวน 2 รอบ, notification/status วน 1 รอบ** แล้วคืนช่องให้ปุ่มลัด
- [ ] เอาเมาส์เข้า-ออก pill ระหว่างข้อความกำลังเลื่อน → ต้องเลื่อนต่อเนื่อง **ไม่หยุดนิ่งกลางทาง**
- [ ] ข้อความเดิมที่เคยเลื่อนจบไปแล้ว พอขึ้นใหม่ต้องเลื่อนใหม่ได้ ไม่ค้างนิ่งโดนตัดครึ่ง
- [ ] การ์ดคำแปลตอนเปิด: pill ข้างล่างต้องกว้างเท่าการ์ดตั้งแต่เฟรมแรก ไม่ใช่ค่อยๆ ยืดตาม
- [ ] การ์ดตอนปิด: fade หายไปเฉยๆ (ถ้าไม่มีพาเนลเปิดอยู่ข้างบน) / ยุบลงพร้อมดึงพาเนลตาม (ถ้ามี)
- [ ] สลับแท็บ History ↔ Vocab ตอนมีประวัติเยอะๆ (50+ แถว) → ต้องไม่หน่วงก่อนพาเนลขยับ
- [ ] scrollbar ในลิสต์โผล่/หายแล้ว **ข้อความไม่ขยับ** (จอง gutter ไว้แล้ว — Windows scrollbar หนากว่า mac ต้องดูว่ากว้างพอไหม)
- [ ] ระหว่าง snip: pill ต้องหุบเหลือตัวเปล่า ไม่มีพาเนล/แถวปุ่มค้างทับกรอบที่กำลังลาก

### สภาพแวดล้อม
- [ ] เกม fullscreen จริง — pill ยังเห็นไหม, snip ทำงานไหม (ทดสอบทั้ง fullscreen แท้และ borderless)
- [ ] จอ 2 จอ — snip บนจอที่ไม่ใช่จอหลัก พิกัดตรงไหม
- [ ] DPI scaling 125% / 150% — กรอบที่ลากตรงกับที่ OCR อ่านไหม
- [ ] เปิดแอปค้างไว้ 2-3 ชม. — แรมบวมไหม เมาส์ยังปกติไหม
