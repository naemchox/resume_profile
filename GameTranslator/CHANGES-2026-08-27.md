## C. บั๊ก CSS ที่เจอระหว่างทาง (ค้างมานาน ไม่ใช่ของใหม่วันนี้)

`renderer/main/styles.css:361` — `.pill.tucked` **ไม่มี `{`** แล้วมีคอมเมนต์คั่น เบราว์เซอร์เลยอ่านรวมเป็น selector เดียว ผลคือ:
- **ไอคอนล็อก (`.pill-lock`) ไม่ได้สไตล์ของตัวเอง** เว้นแต่ pill กำลัง tucked → โผล่มาเป็นแม่กุญแจดิบเกาะขอบ (ตรงกับภาพที่ jek ส่งมา)
- `.dot { animation:none; box-shadow:none }` ที่ควรมีผลเฉพาะตอน tucked **กลายเป็นมีผลกับทั้งแอปตลอดเวลา** → จุดสถานะไม่ pulse ไม่เรืองแสง

แก้แล้ว: คืน scope เป็น `.pill.tucked .dot` และให้ `.pill-lock` เป็นกฎของตัวเอง (ปีกกาสมดุล 594/594)

**หมายเหตุ:** ไอคอนล็อกนี้คือป้ายบอกสถานะ **Lock overlay (⌘⇧L = คลิกทะลุ)** ไม่ใช่ 🔒 แบบ "ต้องจ่ายเงิน" · `git log -S` ไม่พบว่าเคยมีคำสั่งลบมันในรีโปนี้
