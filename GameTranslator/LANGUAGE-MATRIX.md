# ตารางภาษา × ฟังก์ชัน — อะไร "รองรับจริง" กับอะไร "แค่มีในเมนู"
สร้าง 2026-09-03 เพื่อตัดสิน `PRICING-AI.md §12` (จะขายกี่คู่ภาษา) · **อ่านจากซอร์ส ไม่ใช่จากความจำ**

## 2. ปลายทาง (แปลเป็น) — 7 ภาษาในเมนู
th · en · ja · zh-CN · ko · es · vi — ทั้งหมดวิ่งผ่าน endpoint แปลตัวเดียวกัน **ไม่มีโค้ดแยกต่อภาษา** จึง "น่าจะทำงานเท่ากันหมด" 🟡 (ยังไม่เคยเห็นด้วยตาเกิน 1 คู่)

## 3. คูณกันแล้วได้เท่าไหร่
5 ต้นทาง × 7 ปลายทาง = **35 คู่ที่เมนูเปิดให้เลือก** · เคยเห็นทำงานด้วยตาจริง = **eng→th** (คู่เดียว) · jpn hover เคยเห็นในฟอร์ก `GameTranslator-Hover` ไม่ใช่แอปตัวนี้

## 4. ฟังก์ชันไหนพึ่งภาษาแค่ไหน

| ฟังก์ชัน | ผูกกับภาษาต้นทางไหม | ความเสี่ยงถ้าประกาศรองรับหลายภาษา |
|---|---|---|
| **snip → แปล** | ผ่าน OCR | ต่ำ-กลาง · ถ้า OCR อ่านออก ที่เหลือคือ endpoint แปลตัวเดียวกัน |
| **CC (ซับสด)** | ใช้ OCR ตัวเดียวกับ snip วนซ้ำ | เท่ากับ snip · **แต่ผิดถี่กว่ามาก** เพราะยิงทุก 1.2 วิ ไม่ใช่ครั้งเดียว |
| **hover ชี้คำ** | ✅ ผูกตรงๆ | **สูงมาก — จีน/เกาหลี/ไทย ไม่มีพจนานุกรมเลย = ฟีเจอร์ตายเงียบ** |
| **การ์ดเรียน (AI)** | Claude สร้าง ไม่มีข้อจำกัดโค้ด | **สูงที่สุด — ผิดแบบดูไม่ออก** รูปคำ/คำอ่าน/ตัวอย่างประโยคผิดได้โดยหน้าตายังสวย และ jek ตรวจไม่ได้ถ้าอ่านภาษานั้นไม่ออก |
| **คลังคำ / SRS** | ไม่ผูก | ต่ำ · แต่ถ้าการ์ดผิด SRS ก็ท่องของผิดซ้ำๆ |

## 5. ข้อสรุปที่ตารางนี้บังคับ

1. **จีน / เกาหลี ไม่ควรอยู่ในหน้าขาย** — ไม่มีพจนานุกรม hover = ซื้อไปแล้วฟีเจอร์หนึ่งหายไปเงียบๆ (ไม่มีข้อความบอกด้วย)
2. **ไทยเป็นต้นทางบน Mac ไม่มีทางถอย** — ไม่มี `tha.traineddata` ถ้า Vision ล้มคือจบ
3. **คู่ที่ยืนยันได้จริงวันนี้มีคู่เดียว: eng→th** ซึ่ง**ตรงกับที่ jek เสนอพอดี** และตรงกับ default ใหม่ของแอป (`sourceLang: 'eng'` + `targetLang` จาก OS locale)
4. **jpn→th เป็นคู่ที่สองที่ใกล้พร้อมที่สุด** — มี Vision + tesseract + jmdict ครบ ขาดอย่างเดียวคือ**คนตรวจว่าคำแปลถูก** (jek อ่านญี่ปุ่นไม่ออก) → ต้องหาคนช่วยตรวจ หรือปล่อยเป็น "ทดลอง" ไม่ใช่ "รองรับ"
5. **เว็บโฆษณา "Four languages, into yours" = เกินจริงตามตารางนี้** ต้องแก้ก่อนเปิดขาย

## 6. ยังไม่รู้ (ห้ามเดา)
- endpoint แปลคืนคุณภาพเท่ากันทุกปลายทางไหม — ยังไม่เคยเทียบ
- การ์ด AI ภาษาที่ไม่ใช่อังกฤษถูกแค่ไหน — วัดไม่ได้ถ้าไม่มีคนอ่านออก
- ขนาดตลาด "คนไทยเรียนอังกฤษ" เทียบ "คนเล่นเกมญี่ปุ่นบน Mac" — **ยังไม่ได้ค้น**
