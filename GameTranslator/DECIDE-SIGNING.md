> เขียน 2026-08-17 · เรื่องนี้อยู่ใน NEXT.md ข้อ 4 มาตั้งแต่ 6/8 และยังไม่ตัดสิน
> **ผมฟันธงให้แล้วท้ายไฟล์ — ส่วนที่ต้องรอคุณคือการกดจ่าย ไม่ใช่การคิด**

## คำถามที่แท้จริงไม่ใช่ "คุ้มไหม" แต่คือ "เมื่อไหร่"

฿3,300/ปี = **ขาย Pro ฿990 ได้ 3.3 ใบก็คืนทุน** หรือ 0.9% ของเป้า ฿300k/เดือนหนึ่งเดือน
ราคาไม่ใช่ประเด็น สิ่งที่ต้องตัดสินคือ **จ่ายก่อนโพสต์ Reddit หรือหลังมีคนจ่ายเงินคนแรก**

## 1. สิ่งที่พังตอนนี้ (วัดเองแล้ว 8/8/26 ไม่ใช่ทฤษฎี)

ตอนนี้ Gloss เซ็นแบบ **ad-hoc** (`scripts/adhoc-sign.js`) ผลคือ:

```
codesign -d -r-  →  designated => cdhash H"..."
```

macOS ผูกสิทธิ์ Accessibility + Screen Recording ไว้กับ **แฮชของ build นั้นเป๊ะๆ**
แก้โค้ดตัวเดียว build ใหม่ → แฮชเปลี่ยน → **สิทธิ์ถูกปฏิเสธเงียบๆ**

🔴 **จุดที่โหดที่สุด: toggle ใน System Settings ยังเขียวอยู่** (ลิสต์ผูกกับชื่อแอป ไม่ใช่แฮช)
ผู้ใช้เห็นว่า "อนุญาตแล้ว" แต่แอปไม่ทำงาน และ**ไม่มีทางเดาออกเลยว่าต้องลบ-เพิ่มเอง**

**jek เจอกับตัวเอง 8/8 แล้วงงจริง ทั้งที่เป็นคนเขียนแอปเอง** ← นี่คือหลักฐานที่หนักที่สุดในไฟล์นี้
ถ้าคนเขียนแอปยังงง คนที่โหลดจาก Reddit ไม่มีทางแก้ได้

**บรรเทาไปแล้ว** (`2aff1dd`): banner + dialog + ปุ่ม "Show me the app" ชี้ Finder ไปที่ `.app`
**แต่ไม่หาย** — ผู้ใช้ยังต้องนั่งลบ-เพิ่มสิทธิ์เองทุกครั้งที่อัปเดต

## 2. $99 ซื้ออะไร — และไม่ซื้ออะไร

| | ad-hoc (ตอนนี้) | Developer ID ($99/ปี) |
|---|---|---|
| designated requirement | `cdhash` (เปลี่ยนทุก build) | **`identifier + TeamID` (คงที่ข้าม build)** |
| สิทธิ์หลังอัปเดต | 🔴 ตาย เงียบ toggle ยังเขียว | ✅ อยู่ต่อ |
| เปิดครั้งแรก | ต้องเข้า System Settings → Open Anyway | ✅ เปิดได้เลย (หลัง notarize) |
| notarization | ทำไม่ได้ (`Team is not enrolled`) | ✅ **ฟรี ไม่มีค่าเพิ่ม** |
| ค่าใช้จ่ายอื่น | — | ไม่มี — cert/notarize รวมอยู่ในค่าสมาชิกแล้ว |

**สิ่งที่ $99 ไม่ได้ซื้อ** — เขียนไว้กันคาดหวังผิด:
- ไม่ได้ทำให้มีคนโหลดเพิ่ม (ปัญหาคือยังไม่ได้โพสต์ ไม่ใช่ลายเซ็น)
- ไม่ได้แก้ worker ที่ยังไม่ deploy (AI ของทุกคนที่โหลดไปแล้วยังใช้ไม่ได้)
- ไม่ได้ช่วยฝั่ง Windows เลยแม้แต่นิดเดียว

## 3. เหตุผลจริงที่ต้องจ่าย**ก่อน**โพสต์ ไม่ใช่หลังมีคนซื้อ

แผนเดิมเขียนว่า "ตัดสินใจก่อนเก็บเงินคนแปลกหน้า" — **ตรรกะนั้นช้าไปหนึ่งจังหวะ**

หน้าต่างทดสอบ 7 วันหลังโพสต์ = ช่วงที่จะ**แก้บั๊กถี่ที่สุด** เพราะมีคนนอกใช้ครั้งแรก
ทุกครั้งที่ปล่อย build ใหม่ในหน้าต่างนั้น **Gloss ของทุกคนที่โหลดไปก่อนหน้าจะหยุดจับหน้าจอเงียบๆ**

→ เขาจะรายงานว่า **"แอปไม่ทำงาน"** ทั้งที่ OCR ไม่ได้มีปัญหา
→ **นั่นคือ false negative บนการทดสอบที่คุณมีโอกาสยิงครั้งเดียว** (โพสต์ซ้ำ subreddit เดิมไม่ได้)

**ความเสียหายไม่ใช่ ฿99 ที่ประหยัดได้ แต่คือข้อมูลทดสอบที่อ่านไม่ได้** ซึ่งซื้อคืนไม่ได้ด้วยเงินจำนวนใดก็ตาม

## 4. ความเสี่ยงที่บังคับให้ต้องเริ่ม**วันนี้** ไม่ใช่วันโพสต์

| | เวลา |
|---|---|
| ที่ Apple ประกาศ | ยืนยันตัวตน 24–48 ชม. |
| บุคคลธรรมดานอกสหรัฐฯ (= เรา) | ยืดได้ถึง ~2 สัปดาห์ |
| ที่คนรายงานจริงต้นปี 2026 | **2–7+ สัปดาห์ ไม่มีการติดต่อกลับ** |

**นี่คือของที่ซื้อเวลาไม่ได้** ชื่อบนบัตรไม่ตรงนิดเดียวก็โดนขอเอกสารเพิ่มแล้วรออีกรอบ
→ ถ้ารอ "ให้มีคนจ่ายก่อน" แล้วค่อยสมัคร = ลูกค้าคนแรกรอ 2-7 สัปดาห์กว่าจะได้ build ที่อัปเดตแล้วไม่พัง

## ⚖️ คำตัดสิน

### **จ่าย $99 วันนี้ · แต่ห้ามให้มันบล็อกการโพสต์**

เหตุผล 3 ข้อ เรียงตามน้ำหนัก:
1. **lead time ยาวและเดาไม่ได้ (2 วัน – 7 สัปดาห์)** เป็นของชิ้นเดียวในแผนที่เร่งด้วยเงินไม่ได้ → ต้องเริ่มก่อนทุกอย่าง
2. **มันปกป้องการทดสอบ ไม่ใช่แค่ลูกค้า** — สิทธิ์ที่ตายเงียบระหว่างหน้าต่าง 7 วันทำให้ข้อมูลที่ได้อ่านไม่ออก
3. ฿3,300 = Pro 3.3 ใบ · เทียบกับความเสี่ยงที่จะเสียโอกาสโพสต์ครั้งเดียวไปเปล่าๆ **ไม่ใช่การตัดสินใจที่ใกล้เคียงกันเลย**

**ทำขนานกัน:** สมัครวันนี้ → ระหว่างรอ ก็ deploy worker + โพสต์ Reddit ตามแผนเดิมด้วย ad-hoc build ไปก่อน
**ถ้าอนุมัติทันก่อนโพสต์** = โพสต์ด้วย build ที่ notarize แล้ว (ตัดกำแพง "Open Anyway" ออกจากโพสต์ไปเลย)
**ถ้าไม่ทัน** = โพสต์ตามเดิม แต่ **ห้ามปล่อยอัปเดตระหว่าง 7 วันนั้น** เว้นแต่บั๊กระดับใช้งานไม่ได้ และถ้าปล่อยต้องเขียนวิธีรีเซ็ตสิทธิ์ในโพสต์เลย

### เงื่อนไขที่ทำให้คำตัดสินนี้ผิด (เขียนไว้ล่วงหน้า)
- ถ้าโพสต์ไปแล้วครบ 7 วันได้โหลด <20 และไม่มีใครถามราคา → **ไม่ต่ออายุปีที่ 2** ตามเกณฑ์ kill ใน SALES-REDDIT.md
- ถ้าตัดสินใจทิ้ง macOS ไปเอาดีทาง Windows อย่างเดียว → $99 นี้เป็นเงินจม ยอมรับได้ แต่ต้องตัดสินก่อนกด

## สิ่งที่ต้องให้คุณลงมือเอง (ผมทำแทนไม่ได้)

1. สมัครที่ https://developer.apple.com/programs/enroll/ — ต้องเปิด 2FA บน Apple Account ก่อน
2. **ชื่อ-นามสกุลต้องตรงกับเอกสารราชการเป๊ะ** (สาเหตุอันดับ 1 ที่โดนดองเป็นสัปดาห์)
3. จ่าย $99 ด้วยบัตรที่รองรับต่างประเทศ
4. พอได้ Team ID มาแล้วบอกผม → ผมแก้ `package.json` + afterPack hook ให้เลิก ad-hoc แล้วเซ็นด้วย Developer ID + ต่อ notarization เข้า `npm run dist:mac`
