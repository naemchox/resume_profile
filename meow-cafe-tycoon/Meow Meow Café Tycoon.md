# Meow Meow Café Tycoon 🐱☕

แผนโปรเจกต์เกม Roblox แนว Café Tycoon ธีมสัตว์น่ารัก

## 1. เป้าหมาย

- **เป้าหมายรายได้**: กำไร 30,000 บาท/เดือน
- **อัตรา DevEx**: 0.0038 ดอลลาร์ต่อ 1 Earned Robux (ขั้นต่ำถอน 30,000 Earned Robux)
- **คิดคร่าวๆ**: 30,000 บาท ≈ 250,000 Earned Robux/เดือน (ที่ \~34 บาท/ดอลลาร์ ยังไม่รวมค่าโฆษณา ภาษี และค่าธรรมเนียม)
- **ความจริงที่ต้องรู้**: เกมส่วนใหญ่ไม่ติด ต้องปล่อยเร็ว วัดผล และปรับตามข้อมูลผู้เล่นจริง
- **ตรวจอัตรา DevEx ล่าสุดเสมอ** ที่ [https://create.roblox.com/docs/en-us/production/monetization/developer-exchange](https://create.roblox.com/docs/en-us/production/monetization/developer-exchange)

## 2. คอนเซปต์

| หัวข้อ | รายละเอียด |
| --- | --- |
| ชื่อเกม | Meow Meow Café Tycoon |
| แนว | Café Tycoon / Idle ผสมสะสม |
| กลุ่มเป้าหมาย | เล่นได้ทุกวัย เน้นสายชิล น่ารัก |
| จุดขาย | ลูกค้าและพนักงานเป็นสัตว์น่ารัก ตัดคลิปง่าย |
| Core loop | ลูกค้าเข้าร้าน → สั่งเมนู → กดทำ/เสิร์ฟ → ได้เหรียญ → อัปเกรด |

### ลูกค้าสัตว์ (เริ่ม 4 ตัว)

- **แมว**: ใจเย็น สั่งกาแฟ
- **หมา**: ใจร้อน ต้องเสิร์ฟเร็ว
- **กระต่าย**: สั่งน้ำผลไม้/สลัด
- **แพนด้า**: สั่งเยอะ จ่ายหนัก
- **ลูกค้าหายาก**: เช่น หมีขั้วโลก ยูนิคอร์น โผล่สุ่ม ให้โบนัสใหญ่ (จุดตัดคลิป)

### เมนูตั้งต้น

- กาแฟ, คุกกี้/ขนมปัง, นมปั่น
- ปลดล็อกเมนูใหม่ตามระดับร้าน

### อัปเกรดหลัก

- ความเร็วทำเมนู
- จำนวนที่นั่ง
- ราคาขาย
- ผู้ช่วยเสิร์ฟ (สัตว์น่ารัก)

## 3. สูตรทำให้ติดและแชร์ง่าย

1. Core loop สั้น เห็นผลภายใน 10-30 วินาที
2. เป้าหมาย 3 ระยะ: 1 นาที (ได้ของ), 10 นาที (อัปเกรด), หลายวัน (ของหายาก/ระดับร้าน)
3. โชว์ของให้เพื่อนในเซิร์ฟเวอร์เห็น (ร้านสวย พนักงานแรร์)
4. เล่นกับเพื่อนได้: เยี่ยมร้าน ช่วยเสิร์ฟ
5. มีช่วงเวลาตัดคลิปได้: ลูกค้าแรร์ เหตุการณ์ฮาๆ
6. เหตุผลให้กลับมา: ร้านทำเงินออฟไลน์ โบนัสรายวัน อีเวนต์รายสัปดาห์
7. อัปเดตทุก 1-2 สัปดาห์

**หลักจริยธรรม**: ดึงให้กลับมาด้วยความสนุกและรางวัล อย่าลงโทษผู้เล่นที่ไม่ล็อกอิน และอย่าใช้ระบบสุ่มจ่ายเงินแบบพนัน (ผู้เล่น Roblox อายุน้อยเยอะ) ตรวจนโยบายล่าสุดของ Roblox ก่อนทำระบบสุ่มหรือเก็บเงิน

## 4. ระบบเก็บเงิน

### Game Pass (จ่ายครั้งเดียว)

- ผู้ช่วยเสิร์ฟอัตโนมัติ
- x2 เหรียญ
- พนักงานสัตว์พิเศษ

### Developer Product (ซื้อซ้ำได้)

- บูสต์เหรียญชั่วคราว
- ข้ามเวลารอ/เร่งเวลา

### ของแต่ง (ขายได้ตลอด ไม่กระทบสมดุล)

- ของตกแต่งร้าน
- ชุดแต่งตัวพนักงาน

### อื่นๆ

- รายได้ตอนออฟไลน์ (ร้านทำเงินไว้ให้กลับมาเก็บ)
- Premium Payouts จากผู้เล่น Premium

## 5. แผน 4 สัปดาห์

### สัปดาห์ 1: Core loop

- ☐สร้างร้านและเคาน์เตอร์ใน Roblox Studio
- ☐ลูกค้าเดินเข้ามาและต่อคิว
- ☐สถานีทำเมนู (ProximityPrompt)
- ☐รอทำไม่กี่วินาที → เสิร์ฟ → ได้เหรียญ
- ☐ให้ฝั่งเซิร์ฟเวอร์คุมเงินทั้งหมด (กันโกง)

### สัปดาห์ 2: ระบบพื้นฐาน + เทสต์

- ☐อัปเกรด 3 อย่าง (ความเร็ว, ที่นั่ง, ราคา)
- ☐เมนู 3 อย่าง
- ☐เซฟข้อมูลด้วย DataStore
- ☐UI รองรับมือถือ
- ☐ให้เพื่อน 10-20 คนทดลอง ดูว่าเล่นซ้ำไหม

### สัปดาห์ 3: เก็บเงิน + เปิดตัว

- ☐Game Pass และ Developer Product พื้นฐาน
- ☐ของตกแต่งร้าน
- ☐รายได้ออฟไลน์
- ☐ไอคอน, thumbnail, คำอธิบายเกม
- ☐เปิดตัวและลงโฆษณาเล็กๆ ทดสอบ

### สัปดาห์ 4: ทำให้อยากกลับมา

- ☐รางวัลล็อกอินรายวัน (แบบโบนัส ไม่ลงโทษถ้าขาด)
- ☐ปลดล็อกเมนูใหม่ตามระดับร้าน
- ☐เยี่ยมร้านเพื่อน/ช่วยเสิร์ฟ
- ☐อีเวนต์รายสัปดาห์แรก

## 6. หลังเปิดตัว: ตัวเลขที่ต้องดู

| ตัวชี้วัด | ทำไมสำคัญ |
| --- | --- |
| Retention วันที่ 1 | คนกลับมาเล่นพรุ่งนี้ไหม |
| Retention วันที่ 7 | เกมมีเหตุผลให้อยู่ระยะยาวไหม |
| เวลาเล่นต่อรอบ | core loop สนุกพอไหม |
| ผู้เล่นพร้อมกัน (CCU) | ฐานผู้เล่นโตไหม |
| รายได้ต่อผู้เล่น | ระบบเก็บเงินทำงานไหม |

**กฎเหล็ก**: ถ้า retention ต่ำ ให้แก้ core loop ก่อนใช้เงินโฆษณา

## 7. ของที่ต้องเตรียม

- **โมเดลสัตว์**: เริ่มจากรูปทรงง่ายๆ หรือใช้โมเดลที่ได้รับอนุญาตจาก Creator Store (ตรวจสิทธิ์ก่อน)
- **เสียง/เอฟเฟกต์**: เสียงสัตว์ร้อง กระดิ่งตอนได้เงิน
- **ไอคอนเกม**: แมวหน้าตาน่ารัก ตาโต สีสด เห็นชัดแม้ภาพเล็ก
- **Thumbnail 3-5 ภาพ**: ร้านเต็มลูกค้า ลูกค้าแรร์ การตกแต่ง
- **คำอธิบายเกม**: ใส่คำค้นอย่าง "cat cafe" "tycoon"
- **ลิขสิทธิ์**: ห้ามใช้ตัวละคร/แบรนด์สัตว์ที่มีลิขสิทธิ์ (เช่น Hello Kitty, Pokémon) ออกแบบสัตว์ของตัวเอง
- **ตรวจชื่อเกม**: ค้นใน Roblox ว่าไม่ซ้ำ ถ้าซ้ำให้เติมคำท้าย เช่น "Meow Meow Café Tycoon 🐱"
