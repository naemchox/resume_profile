# ทดสอบกฎฐานข้อมูล

ทดสอบ `firestore.rules` และ `storage.rules` กับ Firebase Emulator (ไม่แตะฐานข้อมูลจริง)
ครอบทั้งกรณีที่ต้องอนุญาตและต้องปฏิเสธ — คนนอก · admin · ทีมคลัง · ผู้บริหาร · ดูอย่างเดียว ·
รอกำหนดสิทธิ์ · ถูกปิด/ถอด · คนขับ · admin ชุดแรก · ลิงก์เชิญ · ใบวางบิล (ลูกค้าเปิดลิงก์ · สลิป)

```
cd tests/rules
npm install
npm test          # ต้องมี Java (JDK 11+) และ firebase CLI
```

แก้กฎหรือบทบาทใน `js/access.js` เมื่อไหร่ ให้แก้ทั้งสามที่ให้ตรงกัน แล้วรันชุดนี้ทุกครั้งก่อน deploy
