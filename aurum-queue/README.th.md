# AURUM — Queue & Appointment Atelier

ระบบจองคิวออนไลน์สำหรับ **ร้านเสริมสวยและคลินิกความงาม** สร้างตามลำดับ 5 เฟสใน `queue.md`
และตามคู่มือ `Skill/Website/website_building.md`

เปิดด้วย **VS Code Live Server** ที่ `index.html` ได้เลย — ไม่มี build step, ไม่มี `package.json`,
ไม่ต้องติดตั้งอะไร (ต้องเสิร์ฟผ่าน http ไม่ใช่ `file://` เพราะใช้ ES modules)

```

js/ui.js            เปลือกแอป — ทุกอย่างที่ต้องมีทุกหน้า ผูกไว้ที่นี่ที่เดียว
js/booking.js       Phase 2 — ขั้นตอนการจอง
js/admin.js         Phase 3–5 — กระดาน · ตารางทีม · บริการ · แจ้งเตือน · สถิติ · white-label
js/reminders.js     Phase 4 — คิวแจ้งเตือน 24 ชม. + webhook
```

**ทุกการอ่าน–เขียนผ่าน `store.js` ที่เดียว** ตอนนี้เก็บใน `localStorage`
(คีย์ `aurum.db.v1`) เปลี่ยนไปใช้ Supabase / REST ได้โดยแก้แค่ driver ท้ายไฟล์
ไม่ต้องแตะหน้าจอสักหน้า

**ฟีเจอร์ระดับทั้งแอป (แบรนด์ · nav · toast · reveal · atmosphere) อยู่ใน `js/ui.js`**
หน้าใหม่แค่ `import { shell } from './js/ui.js'` แล้วเรียก `shell()` ก็ได้ครบทุกอย่าง

## Phase 1 — The Core (สิ่งที่ต้องถูกที่สุด)

`availability.js` รับประกัน 2 ข้อ

1. **เวลาที่แสดง = เวลาที่จองได้จริง** — หักเวลานอกกะ · เวลาพัก · วันลา · วันปิดร้าน ·
   คิวที่จองแล้ว **บวกเวลาเก็บงานหัวท้าย** และห้ามจองกระชั้นกว่าที่ตั้งไว้
2. **ตรวจซ้ำตอนบันทึก ไม่ใช่แค่ตอนแสดงผล** — `book()` คำนวณช่วงว่างใหม่จากข้อมูลล่าสุด
   ถ้าคิวใหม่ไม่พอดีในช่วงว่างทั้งก้อน จะ **ปฏิเสธ** พร้อมข้อความ ไม่ปล่อยให้ซ้อน

ทดสอบแล้วครอบคลุม: ช่องที่จองแล้ว · ช่องคาบเกี่ยว · ช่องที่ไม่เว้น buffer · เวลาพัก ·
วันหยุดรายคน · วันปิดร้าน · เบอร์โทรผิดรูปแบบ · ช่างที่ไม่ทำบริการนั้น · จองเกินระยะล่วงหน้า ·
ยกเลิกแล้วคืนช่อง · เลื่อนคิว · เวลาแจ้งเตือนห่างคิว 24 ชม. พอดี

## Phase 2 — โต๊ะจองหน้าเดียว (`book.html`)

สามช่องบนหน้าจอเดียว ไม่มี wizard ไม่มีการกดถัดไป

```
01 ซ้าย    ปฏิทินรายเดือน (เลื่อนเดือนได้)  →  เวลาว่างของวันนั้น
02 กลาง    บริการ + ราคา + ระยะเวลา
03 ขวา     ช่างที่ว่างจริงในวัน–เวลา–บริการนั้น  →  สรุป + ฟอร์ม + ปุ่มยืนยัน
```

**เลือกช่องไหนก่อนก็ได้ ทุกช่องกรองกันเอง** — เบื้องหลังคือ `daySlotMatrix(date)`
ที่คืน `Map<เวลา, Map<บริการ, [ช่าง]>>` ของทั้งวันในรอบเดียว แล้วทั้งสามช่องอ่านจากก้อนเดียวกัน

- เลือก **บริการ** → ปฏิทินหรี่วันที่บริการนั้นเต็ม และเวลาเหลือเฉพาะที่คิวยาวพอ
- เลือก **เวลา** → บริการที่ไม่ว่างช่วงนั้นขึ้นป้าย “ไม่ว่างเวลานี้” และช่องขวาเหลือเฉพาะช่างที่ว่างจริง
- ถ้าเลือกอะไรแล้วมันขัดกัน ระบบล้างเฉพาะตัวที่ขัดแล้วบอกว่าต้องเลือกใหม่ตรงไหน
- ปุ่มยืนยันบอกสิ่งที่ยังขาดเป็นข้อความบนปุ่ม (“เลือกเวลาก่อน” / “กรอกชื่อและเบอร์โทร”)

ช่องซ้ายและขวา **pin ค้างไว้** และเลื่อนในตัวเอง ช่องกลางเป็นตัวกำหนดความยาวหน้า —
ไถดูบริการได้โดยที่ปฏิทินกับปุ่มยืนยันไม่หายไปจากจอ

### บนจอแคบ

| ความกว้าง | เป็นยังไง |
|---|---|
| > 1180px | 3 ช่องเรียงกัน ปุ่มยืนยันอยู่ในช่อง 03 |
| 841–1180px | 2 ช่อง (ช่อง 03 เต็มความกว้างด้านล่าง) + **แถบยืนยันติดขอบล่าง** |
| ≤ 840px | เรียงลงมาเป็น 3 ขั้น หัวข้อขั้นเกาะใต้แถบเมนู + แถบยืนยันติดขอบล่าง |
| ≤ 420px | ช่องเวลา 3 คอลัมน์ตายตัว ระยะขอบแคบลง |

พอสามคอลัมน์แตก **ปุ่มยืนยันย้ายออกจากช่อง 03 ไปอยู่ในแถบล่างที่เห็นตลอด** พร้อมสรุป
"บริการ · วัน · เวลา · ราคา" และตัวปุ่มบอกสิ่งที่ยังขาด — แตะแล้วเลื่อนไปหาขั้นนั้นให้เลย
พอจองสำเร็จแถบก็หายไปพร้อมระยะเผื่อของมัน (ผูกด้วย `body:has(#deskbar)` จึงไม่รั่วไปหน้าอื่น)

บนมือถือแถบเมนูบนสุด **สูงคงที่ 53px ไม่ยุบตอนเลื่อน** (เหลือแค่มาร์กกับชื่อร้าน)
เพื่อให้หัวข้อขั้นที่เกาะอยู่ใต้มันวางได้พอดีเป๊ะ ไม่ขยับตามตอนสกรอลล์

### โหมด minimal

หน้าจองใช้โทน **Noir minimal** — พื้นเดิมของแบรนด์ แต่ถอดของประดับออกหมด
เหลือแต่ตัวอักษร เส้นผม และที่ว่าง สั่งด้วย `<body class="minimal">` + `css/book-minimal.css`
ซึ่งโหลดเฉพาะหน้านี้ ทุกกฎขึ้นต้นด้วย `body.minimal` **หน้าอื่นในเว็บจึงไม่ขยับเลย**

หัวใจของการถอดคือบรรทัดเดียว — `--foil: var(--c-action)` เปลี่ยนไล่เฉดทองให้เป็นสีเรียบ
แล้วทุกชิ้นที่เคยใช้ทอง (ปุ่ม วันที่เลือก มาร์ก ชื่อร้าน) แบนราบตามทันทีโดยไม่ต้องไล่แก้ทีละตัว

| เดิม | minimal |
|---|---|
| การ์ดมีพื้น–ขอบ–เงา | ไม่มีกล่อง แบ่งด้วยเส้นผมแนวตั้ง/แนวนอน |
| ชิปเวลามีกรอบ | ตัวเลขในกริด เลือกแล้วเป็นสีทอง + ขีดเส้นใต้ |
| การ์ดบริการ | แถวบนเส้นผม เลือกแล้วมีกลีบทองนำหน้า |
| อวตารกลีบทอง | ตัวอักษรในวงกลมเส้นผม |
| เกรน + ฝุ่นทองลอย + watermark | ตัดออกทั้งหมด |
| ช่องกรอกมีพื้นและกรอบ | เส้นใต้บรรทัดเดียว |
| hover ยกตัว + เงา | เปลี่ยนสีอย่างเดียว 180ms |

ถ้าอยากได้กลับเป็นแบบเดิม ลบ `class="minimal"` กับบรรทัด `<link>` ในหัวไฟล์ออกก็จบ

## Phase 4 — Webhook

ตั้ง URL ปลายทางได้ที่ **แจ้งเตือนอัตโนมัติ** ระบบ POST JSON:

```json
{ "event":"appointment.reminder",
  "to":{"name":"...","phone":"..."},
  "appointment":{"code":"AU-7K2F","date":"2026-09-03","start":"12:15","service":"...","staff":"...","price":1800},
  "text":"ข้อความไทยพร้อมส่ง" }
```

ต่อกับ LINE Messaging API · SMS gateway · Make · Zapier ได้ตรง ๆ
ถ้าไม่เปิดใช้งานจริง ระบบจะทำงานใน **โหมดทดลอง** — บันทึกข้อความที่จะส่งไว้ให้กดดูได้

**กติกาของคิวแจ้งเตือน** — จองกระชั้นกว่า 24 ชม. งานจะขึ้นสถานะ `skipped`
แต่ถ้าคิวนั้นถูก **เลื่อนออกไปไกลขึ้น งานจะถูกปลุกกลับมาเป็น `scheduled` อัตโนมัติ**
ทั้งจาก `reschedule()` และจาก `reconcile()` ส่วนงานที่ `sent`/`failed` ไปแล้วจะไม่ถูกแตะซ้ำ

## Phase 5 — White-label

หน้า **แบรนด์และข้อมูล** เปลี่ยนชื่อร้าน · ข้อความใต้ชื่อ · เฉดสี · ความเข้ม ·
พื้นเข้ม/พื้นครีม แล้วทั้งระบบเปลี่ยนตามทันทีรวมถึง favicon
(สีทั้งชุดสร้างจากเฉดเดียวด้วยสูตร 9 ระดับ จึงคุมค่าความต่างของตัวอักษรไว้ได้)
ส่งออก/นำเข้าฐานข้อมูลทั้งก้อนเป็น JSON ได้จากหน้าเดียวกัน

## หมายเหตุงานออกแบบ

- **Signature:** *The Gilded Ledger* — ใบจองปั๊มทองที่ค่อย ๆ ประกอบตัวเองขณะเลือก
  และตารางเวลาที่เรนเดอร์เป็นสมุดบัญชีแทน calendar widget
- **Motif:** กลีบทองปลายเรียวมีรอยบากเยื้องศูนย์ (วาดเป็น SVG path เอง) ใช้ 8 บทบาท —
  bullet · เส้นคั่น · watermark · avatar mask · loader · nav marker · toast · favicon
- **Atmosphere:** ฝุ่นทองลอยในลำแสง (ระบบเดียวทั้งเว็บ, หยุดเองเมื่อเลื่อนพ้นจอ)
- **Reduced motion:** ปิดทุกอย่างแล้วหน้ายังอ่านครบและยังสวย
- **ตัวอักษรไทย:** display line-height ≥ 1.22 เสมอ — ต่ำกว่านี้วรรณยุกต์บนสระบนจะโดนตัด
